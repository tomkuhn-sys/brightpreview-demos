# BrightPreview demos

Standalone demos, published to Firebase Hosting (project `holiday-mockups-dev`, site `brightpreview-demos`) on every push to `main`.

- `/dropzone` — Drop Zone Picker
- `/roofline` — Roofline Measure (Google Solar API + Photorealistic 3D Tiles). Needs a browser key with Solar API, Map Tiles API (and optionally Geocoding API). Geometry tests: `node tests/roofcalc.test.mjs`
